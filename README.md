Проєкт: Executive E-commerce Dashboard (Power BI)

Бізнес-задача: Створити мінімалістичний, швидкий та інтуїтивно зрозумілий дашборд для топ-менеджменту, який забезпечує швидкий доступ до ключових метрик продажу (виручка, кількість, середній чек) без зайвого візуального захаращення.

Архітектура та Інтерфейс (UI/UX):

Сформовано чисту ієрархію екрана з акцентом на головні KPI-картки у верхній частині.

Налаштовано сучасну навігацію за допомогою Button Slicer (кнопкові фільтри місяців).

Реалізовано архітектуру сторінок-підказок (Tooltip Page): при наведенні на товарні категорії замість захаращення основного екрана з'являється компактний географічний розріз (продажі по містах).

Моделювання та Аналітика:

Зведено наявний масив даних у єдину робочу модель.

Написано чисті міри для коректного розрахунку загальної виручки, кількості та середнього чека.

Проведено перевірку продуктивності через Аналізатор ефективності (Performance Analyzer), досягнуто еталонного часу завантаження візуалів (у межах 200–240 мс).
